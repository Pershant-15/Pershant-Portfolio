# portolio2

Personal portfolio built with React, Vite and Tailwind CSS v4. The animated background is the
Particles component from React Bits (reactbits.dev), which uses OGL.

## Run it

```bash
npm install
npm run dev
```

Open the local address Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Make it yours

- Edit `src/data.js` for your name, links, projects, skills and education.
- Tune the background in `src/App.jsx` (particle count, colours, speed, hover movement).
- Theme colours and fonts live in `src/index.css` under `@theme`.
